Green-Finance Banking & Telemetry API

1.0.0 OAS 3.0

Simulated banking microservices with integrated Kepler energy telemetry. Every executed money transfer creates double-entry balance updates, increments Prometheus request counters, and calculates carbon intensity.

Base URL: http://localhost:8000 OpenAPI JSON: /openapi.json
POST /auth/login User Authentication & JWT Token Generation (RF01) ▼

Authenticates bank customer and returns a signed JWT access token containing User ID and registered Bank ID.

Double-Entry Financial & Carbon Ledger

Strict bookkeeping balance sheet ensuring every transfer registers balanced debits, credits, and carbon liabilities.

System Configuration & Alert Rules (RF07 / RF10)

Configurable environment parameters and ESG thresholds in accordance with IEEE 830 specification.

Regional Carbon Intensity Factor

Multiplier converting electric kilowatt-hours to grams/kg of CO₂ emissions.

India National Grid Average benchmark is approx. 0.38–0.42 kg CO₂/kWh.
Default is 15s per SRS specification (RNF05).

RF07 Carbon Threshold Alerts

Threshold that triggers automated alerts in Grafana and UI notification banners.

Transactions generating more than this threshold trigger immediate warning banners.
